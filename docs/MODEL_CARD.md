# Model card — финальная модель «Меню от нейросетей»

## 1. Что и зачем

| | |
|---|---|
| Задачи | (A) тип блюда по ингредиентам — 9 классов; (B) название блюда; (C) ответ «что приготовить» по базе рецептов |
| Пользователи | кулинарные сервисы, повара, учебная демонстрация; **не** для медицинских/диетических решений |
| Язык | английский (ингредиенты Epicurious); русский ввод распознаётся как неизвестные слова → предупреждение |
| Версия | бандл `1.0.0` (тег `v1.0.0` в HF-репозитории модели), пакет `menu-from-nn 1.0.0` |

## 2. Как выбиралась финальная модель (Task 1)

Кандидаты — все модели из Assignments 3–4; критерий выбора — **validation**, test используется один раз для отчёта.

**Классификация.** Лучшая в A4 — `LinearSVC` после GridSearch (144 конфигурации): test macro-F1 **0.710**, лучше
DistilBERT (0.698) и в ~1000 раз быстрее на CPU. Для inference внесено одно изменение, проверенное на validation:

| вариант | val macro-F1, строки с количествами | val macro-F1, только названия | test, строки | test, названия |
|---|---|---|---|---|
| A4: обучение на `ing_raw` | 0.725 | 0.634 | 0.710 | 0.632 |
| **финал: обучение на `ing_raw` + `ing_clean`** | **0.734** | **0.697** | **0.719** | **0.669** |

Пользователи вводят ингредиенты без количеств («rum; lime; mint»), поэтому модель, обученная на обоих форматах,
корректнее обрабатывает новые входные данные. Вероятности — `softmax(decision / T)`, `T = 0.313` подобрана на
validation по NLL (argmax не меняется; ECE на test 0.033; при уверенности ≥ 0.6 точность 0.87 на 69 % запросов).

**Генерация названия.** Лучшая в A4 — Qwen2.5-0.5B-Instruct + LoRA, beam=4: ROUGE-L **0.386**. В финальном проекте
добавлен RAG; `notebooks/final_training` обучает `lora` (повтор A4) и `lora_rag` и выбирает победителя на validation
по критерию, зафиксированному в A4:

`score = 0.5·ROUGE-L + 0.3·anchored + 0.2·novelty − unsupported − (1 − valid)`; при равенстве — меньше `context_copy`.

| вариант | адаптер | RAG k | что проверяет |
|---|---|---|---|
| Qwen zero-shot | — | 0 | перенос знаний без обучения |
| Qwen zero-shot + RAG | — | 3 | даёт ли контекст эффект без обучения |
| Qwen + LoRA (A4) | `lora` | 0 | лучшая модель A4 |
| Qwen + LoRA (A4) + RAG | `lora` | 3 | контекст для модели, не обученной с ним |
| Qwen + LoRA-RAG | `lora_rag` | 3 | обучение и inference в одном формате |

Выбранный вариант записывается в `manifest.json → generator.final_variant` и используется режимом `auto` API/UI.
Таблицы validation/test этого прогона — в `manifest.json → generator.evaluation` и на вкладке «О модели».

**Retriever.** BM25 по ингредиентам, база знаний — только train (14 543 рецепта). На validation: ROUGE-L названия
ближайшего соседа 0.225 (TF-IDF из A4 — 0.185), совпадение типа блюда у 3 соседей 0.51 (0.46). Для чата —
гибрид BM25 + `all-MiniLM-L6-v2` (RRF).

## 3. Вход и выход

**Вход** (`POST /v1/menu`, `/v1/classify`, `/v1/generate`):

| поле | тип | ограничения |
|---|---|---|
| `ingredients` | `list[str]` или `str` (разделители `;` / перевод строки) | 1–40 строк, ≤160 символов, хотя бы одна буква; пустые и дубли удаляются |
| `top_k` | int | 1–9 (классификация) |
| `mode` | `auto \| lora \| lora_rag \| zero_shot \| zero_shot_rag` | `auto` = финальный вариант |
| `rag_k` | int | 0–8 (для RAG-режимов) |

Предобработка: для классификатора строки склеиваются в `ing_raw` (`" ; "`), для генератора и поиска —
`clean_ingredient` → `ing_clean` (единицы, количества и способы нарезки удаляются).

**Выход:**

| поле | смысл |
|---|---|
| `dish_type`, `confidence`, `top[]` | класс и откалиброванные вероятности |
| `low_confidence` | `confidence < 0.4` |
| `title`, `valid` | название (1–15 слов) |
| `context[]`, `context_copy` | найденные рецепты и флаг «название скопировано из контекста» |
| `degraded` | LLM недоступна, ответил fallback по ближайшему рецепту |
| `meta.model_version`, `meta.latency_ms`, `meta.warnings` | версия бандла, задержка, предупреждения (неизвестные слова, низкая уверенность) |

Полные JSON-схемы: `GET /v1/model` и `/docs`.

## 5. Ограничения и риски

* Метки типа блюда построены **эвристически** из тегов (правило «первый совпавший»), часть меток шумная.
* Appetizer и Breakfast & Bread — самые трудные классы (F1 ≈ 0.35–0.55).
* ROUGE-L сравнивает с **одним** эталоном, а правильных названий много; дополняется anchored/unsupported/novelty.
* Модель генерирует **только название**; описания и рецепты не генерируются (в A3 описания были шаблонными).
* Чат-ассистент на 0.5B модели может не сослаться на рецепт → флаг `grounded=false` и список источников всегда
  показывается.
* Один seed обучения; доверительные интервалы не оценивались.
